# DXFka

Пакетный экспорт DXF из деталей сборок **КОМПАС-3D v24**.

Автор и поддержка: **Djonros** — djonros@gmail.com

## Что делает

- Открывает сборку (`.a3d`), рекурсивно обходит все детали (`.m3d`),
  включая вложенные подсборки, исполнения и локальные детали (встроенные
  в сборку, без своего файла); дедуплицирует их и пропускает
  стандартные/библиотечные изделия. Исполнение — отдельный DXF
  с суффиксом «-NN» в имени.
- Определяет листовые детали через API листового моделирования КОМПАС
  (`ISheetMetalBody`) и автоматически строит развёртку (`Straighten`).
- Два режима (меню «Обработка»):
  - **Автоматически** — толщина берётся из листового тела, а для пластин
    из выдавливания — из материала («Лист$d8 ГОСТ …»); развёртка и DXF
    делаются без остановок (у пластины выбирается проекция с наибольшим
    контуром); остановка только на деталях без толщины;
  - **Вручную** — пауза на каждой детали: вы проверяете развёртку, правите
    вид во фрагменте (поворачиваете, удаляете лишние надписи), вводите
    толщину и жмёте «Продолжить».
- Готовые DXF раскладываются по подпапкам с именем толщины внутри
  папки DXF.
- Можно задать свой шаблон фрагмента (`.frw`) — фрагменты создаются по
  нему, и надписи удалять не приходится.
- Результат: DXF 1:1 в миллиметрах, только контур детали: рамки и штампа
  нет, подпись масштаба «(1:1)» и другие надписи вида удаляются
  автоматически. DXF без контура считается ошибкой.
- Подробный журнал (`kompas_dxf_exporter.log`) и статусы по каждой детали;
  журнал в GUI открывается по запросу — «Файл → Показать журнал».

## Как получить

Готовый `kompas_dxf_exporter.exe` скачивается со страницы
[Releases](https://github.com/Djonros/DXFka/releases): откройте нужный
релиз и в разделе **Assets** заберите `kompas_dxf_exporter.exe`.
Установка не требуется.

Если подходящего релиза нет — напишите на djonros@gmail.com.

Пробная версия: 10 успешных экспортов. Полная версия — по лицензии,
привязанной к компьютеру (HWID видно в диалоге «Лицензия…»).

## Запуск из исходников

1. Windows 10/11, Python 3.10+, установленный КОМПАС-3D v24.
2. `pip install pywin32`
3. `python kompas_dxf_exporter.py` (или `kompas_dxf_exporter.pyw` без консоли)
4. Программа и КОМПАС должны быть запущены с одинаковыми правами
   (оба обычные или оба от администратора).

Лицензирование в сборках из исходников работает в режиме разработки
(пробная версия; см. `license_secret.example.py`). Счётчик пробной версии
режима разработки хранится отдельно (`state.dev.json`, ключ реестра `...\Dev`),
поэтому запуск из исходников больше не «повреждает» состояние exe-сборки.

## Сборка exe

```
python -m pip install pywin32 pyinstaller
python -m PyInstaller --noconfirm --clean kompas_dxf_exporter.spec
```

Готовый файл: `dist\kompas_dxf_exporter.exe`.

## Состав

| Файл | Назначение |
|---|---|
| `kompas_dxf_exporter.py` | Точка входа (запуск и сборка exe) |
| `kompas_dxf_exporter.pyw` | Запуск без консоли |
| `dxfka/config.py` | Константы приложения, лицензирования, КОМПАС API |
| `dxfka/licensing.py` | HWID, пробная версия, файл лицензии |
| `dxfka/models.py` | Данные детали, исключения потока экспорта |
| `dxfka/kompas/` | Подключение к КОМПАС, обход сборки, экспорт в DXF |
| `dxfka/worker.py` | Рабочий поток (весь COM выполняется только здесь) |
| `dxfka/ui/` | Графический интерфейс (tkinter) |
| `dxfka/utils.py`, `dxfka/compat.py` | Утилиты, журнал, настройки; pywin32 |
| `kompas_dxf_exporter.spec` | Сборка PyInstaller |
| `ИНСТРУКЦИЯ.txt` | Инструкция пользователя (кладётся рядом с exe) |
| `license_secret.example.py` | Шаблон секрета лицензирования |

Инструкция для пользователя встроена в программу: меню
«Справка → Инструкция» (показывается и при первом запуске).

## Технологии

- Python 3, tkinter, pywin32 (COM).
- КОМПАС-3D API: API5 (`KompasObject`, `Document2D`, `ksCreateSheetArbitraryView`,
  `ksSaveToDXF`) и API7 (`IApplication`, `IPart7`, `ISheetMetalBody`,
  `IDocuments`).
