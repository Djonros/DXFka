ШАГ 0. ПОДГОТОВКА
-----------------------------------------------------
1. Запустите КОМПАС-3D v24 (если он не запущен, программа
   запустит его сама — это дольше).
   ВАЖНО: программа и КОМПАС должны быть запущены с одинаковыми
   правами (оба обычные или оба от администратора), иначе
   подключение не сработает.
2. В КОМПАС ничего открывать не нужно — программа сама откроет
   нужные документы.
3. (Необязательно, ускоряет работу) Один раз создайте шаблон
   фрагмента: в КОМПАС Файл -> Создать -> Фрагмент, при желании
   удалите всё лишнее, Файл -> Сохранить как шаблон (.frw).
   Затем в программе в поле «Шаблон фрагмента» укажите этот файл
   (кнопка «Обзор…»). Новые фрагменты будут создаваться по этому
   шаблону — надписи не придётся удалять вручную.
   Выбор запоминается между запусками; «Сброс» — вернуть
   стандартный пустой фрагмент.


ШАГ 1. ВЫБОР СБОРКИ И АНАЛИЗ
-----------------------------------------------------
1. Нажмите «Выбрать сборку» и укажите файл сборки (.a3d).
2. Нажмите «Анализировать». Программа обойдёт сборку (включая
   подсборки) и покажет список деталей.
3. В списке отмечены галочками только детали, похожие на листовые
   (в материале есть слово «лист»). Нелистовые — без галочки.
   Снимите или поставьте галочки вручную, если нужно.
   Тип «не определён» уточнится при экспорте автоматически.
4. Нажмите «Экспортировать выбранные».


ШАГ 2. ЭКСПОРТ — ЧТО ДЕЛАТЬ НА ПАУЗАХ
-----------------------------------------------------
Программа обрабатывает детали по одной. Для каждой детали
появляются ОКНА С ИНСТРУКЦИЕЙ — окно КОМПАС при этом
активируется автоматически.

ПАУЗА 1 (только для листовых деталей): «Развертка построена —
проверьте»
  - В окне КОМПАС проверьте развертку детали.
  - Если нужно — скорректируйте ориентацию модели.
  - Запомните нужный вам вид детали для резки
  - Нажмите «Продолжить» в окне программы.
  «Пропустить деталь» — без создания DXF для этой детали.

ПАУЗА 2: «Проверьте вид во фрагменте»
  - В окне КОМПАС создан чертёж-фрагмент с видом детали.
  - Поверните вид правильной стороной: щёлкните по виду,
    чтобы выделить его, и поверните.
  - Удалите лишние надписи и обозначения (линии сгибов, оси
    и т.п.), если они есть.
  - Нажмите «Продолжить» — программа автоматически ПЕРЕСТРОИТ
    чертёж (Ctrl+R не нужен) и сохранит его в DXF в
    отредактированном виде.
  «Пропустить деталь» — без сохранения DXF.
  «Отмена» — остановить всю обработку.

После каждой детали в списке появляется статус: OK / ОШИБКА /
ПРОПУСК. Готовые файлы DXF лежат в папке вывода (задаётся
в программе, по умолчанию рядом со сборкой, DXF_Out).


ПОДСКАЗКИ
-----------------------------------------------------
- Всегда проверяйте созданные детали в каком-нибудь просмотрщике DXF.
- Масштаб вида всегда 1:1, рамки и штампа во фрагменте нет —
  в DXF остаётся только геометрия.
- Если вид построился не с той стороны — не переделывайте
  в КОМПАС вручную, просто поверните вид на ПАУЗЕ 2.
- Формат и единицы DXF берутся из настроек КОМПАС:
  Параметры -> Совместимость -> форматы обмена
  (рекомендуется: ASCII, мм).
